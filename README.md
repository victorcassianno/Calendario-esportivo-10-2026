# ⚽ Futebol Europeu

Site de notícias e programação de jogos do futebol europeu, desenvolvido com HTML, CSS e JavaScript.

## 📋 Sobre o projeto

Este projeto apresenta uma página inspirada em portais esportivos, com foco na programação de partidas de grandes clubes do futebol europeu.

O site possui um visual moderno com tons pastéis, cards de partidas e filtros por equipe.

## 🏆 Clubes

O site apresenta jogos de:

- 🔵 Manchester City
- 🔴 Arsenal
- ⚪ Real Madrid
- 🔵 Barcelona
- 🔴 Bayern de Munique

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- 📅 Programação de jogos
- 🔎 Filtro por clube
- 📱 Design responsivo
- 🎨 Interface com tons pastéis
- ⚡ JavaScript integrado ao HTML
- 🖥️ Compatível com computadores e celulares
- 🌐 Favicon personalizado
